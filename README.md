# Sistema Financeiro Pessoal (SFP)

Um aplicativo que substitui sua planilha financeira. Organize seus ganhos, gastos, cartões de crédito, investimentos e planejamento financeiro em um único lugar.

## O que você consegue fazer

- 📊 **Controlar seu dinheiro**: Saiba exatamente quanto você ganha e gasta
- 💰 **Gerenciar contas**: Múltiplas contas e cartões em um só lugar
- 💳 **Parcelar compras**: Controle suas compras parceladas no cartão
- 📈 **Acompanhar investimentos**: Monitore onde seu dinheiro está aplicado
- 🎯 **Simular compras**: Veja o impacto de uma compra antes de fazer
- 📅 **Organizar por período**: Visualize gastos mensais, anuais ou em períodos personalizados

## Como começar

1. Ter Java 21+ e Maven instalados
2. Clonar o projeto: `git clone ...`
3. Ir à pasta do projeto e rodar: `mvn spring-boot:run -Dspring-boot.run.arguments="--spring.profiles.active=dev"`
4. Acessar a documentação completa da API em: **http://localhost:8080/swagger-ui/index.html**

## Onde está a documentação?

Toda a documentação técnica da API (endpoints, parâmetros, exemplos) está no **Swagger** dentro da aplicação. Não tem nada em arquivo.

Você verá:
- Todos os endpoints disponíveis
- O que cada um faz
- Exemplos de como usar
- Como fazer login e autenticação

## Suporte e desenvolvimento

Para integrar com um frontend ou contribuir, consulte o **Swagger UI** para ver exatamente como a API funciona.
